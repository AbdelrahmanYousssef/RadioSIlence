How the trust map is made

  1. Start from a full scan. The fully sampled k-space gives the ground-truth image (root-sum-of-squares over the 20 coils, cropped to 320×320).
  2. Throw most of it away. Keep only every 4th (or 8th) line of k-space plus the center, as a 4× or 8× faster scan would.
  3. Let the AI fill in the gaps. A pretrained end-to-end VarNet (fastMRI brain leaderboard model, no retraining) reconstructs the image.
  4. Ask it again, slightly differently, 10 times. Each time, randomly leave out ~5% of the lines that were measured (never the center ones). This only uses data a real fast scan actually has.
    Where the 10 answers disagree, the model is guessing. The pixel-wise standard deviation is the trust map (bright = low trust).
  5. Check it against reality. The error map is |reconstruction − ground truth|. Radiologist lesion boxes from fastMRI+ show whether the guessing happens where the clinically important tissue is.

In a real accelerated scan there is no ground truth, so the error map can't be computed. The trust map can, because it only needs the undersampled data and the model. This is a research prototype, not a diagnostic tool.
